go.smritikosh.in

Vanity import paths for SmritiKosh Go modules (ADR-028), so source code never embeds the GitHub organisation name and the organisation can be renamed or moved without touching a single import.

The modules themselves are in private repositories. Set GOPRIVATE=go.smritikosh.in/* and authenticate to GitHub to fetch them.

This host serves meta tags only. It is deliberately a subdomain: the apex smritikosh.in stays free for the product, so pointing it at AWS later cannot break Go resolution.
